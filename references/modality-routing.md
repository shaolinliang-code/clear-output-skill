# 载体选择与准确性

选择最低复杂度、足以回答问题的组合；不把文字→表格→图→交互→视频当升级阶梯。

| 载体 | 值得使用的条件 | 必须保留／避免 |
|---|---|---|
| 文字 | 直接回答、论证、细微差别、条款 | 定义、限定及原任务；不用装饰代替解释 |
| 表格 | 多方案按同一维度精确比较 | 单位、共同口径；控制列数及长段落，考虑手机阅读 |
| 图表／示意图 | 趋势、比较、组成、分布、关系、流程、时间线 | 数据来源与解释；概念图注明非量化，不伪造数值 |
| 交互网页／模拟 | 改变量、比较情景或探索路径有实际收益 | 默认情景、变量解释、计算依据与静态替代 |
| 视频／动画 | 时间或空间过程静态难讲清且读者需要观看 | 文字摘要、字幕或文字稿；不以视频掩盖依据 |

## 图表检查

- 图形类型匹配实际问题。柱状图用长度比较时原则上从零起；确需截断坐标则清晰标示、解释并避免夸大差异。
- 标出来源、日期、单位、样本／口径及必要限制。缺失数据不能画成零；不虚构“示意数据”。
- 图与正文采用相同数据；展示精度与计算值差异须说明。不要用双轴、面积或视觉尺寸暗示不存在的数量关系。
- 颜色不独自承担意义，同时使用文字、标签、线型或形状；检查对比度、字号、阅读顺序与图文间距。
- 复杂图提供文字解释及可访问数据表，让不能看图的人仍能理解主要关系。
- 概念图可以没有数值，但明确关系是机制假设、示例还是有证据支持，避免把关系箭头冒充因果证据。

## 交互检查

区分用户输入、固定假设、计算结果与推断；标注单位、合法范围、默认值、公式及局限。实际测试默认路径、主要交互和极端输入（零、负值、空值、范围外值及边界），防止除零、单位错配和不可理解错误。

用户不能访问交互版本时提供静态说明或可下载的数据替代；没有可用执行工具时不要声称已运行或测试。生成、上传、公开发布分别遵守用户授权。

## 文件与设备检查

实际检查生成文件可打开、文字无明显裁切、图表标签可见；按用户要求保留可编辑对象。不把整页截图称为可编辑幻灯片。预览器通过只证明预览器检查；没有在指定软件或设备打开，就报告该项未实测。
